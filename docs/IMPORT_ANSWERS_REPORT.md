## 5. Отступления от задания и найдено вне задания

### Отступления

- **`answer_explanation` без ключа не меняется**, явный `null` его стирает.
  В задании поле необязательное, а что делать при его отсутствии, не
  сказано; так повторный вызов только с ответом не стирает разбор.
- **Текст `[bad_answer]` не содержит ответа** (у `admin_upsert_task` —
  «Ответ «…» не соответствует формату»): сообщение уходит в вывод клиента.
- **`--publish` только публикует**, ответы заливает запуск без флага. Перед
  первой публикацией скрипт проверяет все отобранные задачи (`get_task`:
  файлов нет, ответ, формат и эталон совпадают с `solutions.json`, эталон
  сверен) и лишь потом публикует — чтобы на ошибке не остаться с частью
  публикаций. Уже опубликованные пропускаются.
- **Темп считает все вызовы `admin_*`**, включая `admin_get_task`, хотя
  лимит базы считает только записи (строки `audit_log`). Так задание
  читается буквально; выходит медленнее, но с запасом.
- В `verify_reference` уходит вывод эталона без пробельных краёв
  (`strip()`), как в `import_repo_tasks.py`: база обрезает края только от
  пробелов (см. ниже). Эталон запускается как `python3 -I` из временного
  файла.
- Скрипт сверяет, что под `slug` в базе лежит то самое задание банка
  (`origin = 'fipi'`, `fipi_short_id` совпадает с шифром), иначе стоп.

### Найдено вне задания

- **`normalize_answer` срезает с краёв только пробелы** (`btrim` без
  второго аргумента), а переводы строк и табуляции превращает в пробел.
  Поэтому `"42\n"` для `single` — `null` (ответ не совпадёт), для `string` —
  `"42 "` с пробелом на конце. Клиент отправляет ответ как ввёл ученик
  (`SubmitAnswerUseCase` проверяет только пустоту). Не исправлялось.
- **«Взять из вывода» берёт последнюю непустую строку** вывода. У табличных
  ответов (`multi`, числа по строкам таблицы) естественный вывод — несколько
  строк, и кнопка подставит только последнюю. Среди 139 публикуемых `multi`
  8, все — номер 25; у 7 из них в таблице от 5 до 9 строк. Это часть пункта
  «подсказка о форме ответа».
- У `tools/content_client.py list --origin` выбор только `human`/`ai`, без
  `fipi`. Не исправлялось.
