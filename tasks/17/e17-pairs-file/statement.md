Откройте файл 17.txt. Он содержит последовательность из 5000 целых чисел, каждое из которых по модулю не превышает 10 000. Каждое число записано в отдельной строке.

Определите количество пар последовательности, в которых хотя бы один из двух элементов оканчивается на ту же цифру, на которую оканчивается минимальное положительное число последовательности, а сумма элементов пары кратна 3.

В данной задаче под парой подразумеваются два идущих подряд элемента последовательности. Считается, что число оканчивается на некоторую цифру, если на эту цифру оканчивается десятичная запись модуля этого числа.

В ответе запишите два числа через пробел: сначала количество найденных пар, затем максимальную из сумм элементов таких пар.
