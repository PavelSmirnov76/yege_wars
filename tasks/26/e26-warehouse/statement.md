Оптовая база принимает на хранение партии товара. Свободный объём хранилища составляет S условных единиц. В каждой заявке указан объём одной партии; заявка либо принимается целиком, либо отклоняется, разделять партию на части нельзя. Суммарный объём всех принятых партий не должен превышать свободный объём хранилища.

В первую очередь база стремится принять как можно больше заявок. Если наибольшее количество заявок можно набрать несколькими способами, то среди них выбирают тот, при котором объём самой большой принятой партии максимален.

Откройте файл 26.txt. В первой строке записаны два целых числа: N — количество заявок и S — свободный объём хранилища (в условных единицах). Каждая из следующих N строк содержит одно целое число — объём партии по соответствующей заявке (в условных единицах).

Определите наибольшее количество заявок, которые можно принять, и максимально возможный при этом количестве объём самой большой принятой партии.

В ответе запишите два целых числа через один пробел: сначала наибольшее количество принятых заявок, затем максимально возможный объём самой большой принятой партии.
