Задание выполняется с использованием прилагаемых файлов 27_A.txt и 27_B.txt.

Оба файла имеют одинаковую структуру. Первая строка файла содержит число N — количество чисел в последовательности. Каждая из следующих N строк содержит одно натуральное число, не превосходящее 10 000 000. В файле 27_A.txt N = 1000, в файле 27_B.txt N = 200 000.

Из последовательности необходимо выбрать два числа, порядковые номера которых в последовательности различаются не менее чем на 20. Среди всех таких пар, сумма чисел которых кратна 173, требуется найти пару с максимально возможной суммой. Гарантируется, что в каждом файле хотя бы одна такая пара есть.

Определите максимально возможную сумму такой пары для каждого из файлов.

В ответе запишите два числа через один пробел: сначала ответ для файла 27_A.txt, затем — ответ для файла 27_B.txt.
