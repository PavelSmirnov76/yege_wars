На вход автомата подаётся натуральное число N. По этому числу строится новое число R следующим образом.

1. Строится двоичная запись числа N.
2. Если количество единиц в двоичной записи числа N чётно, то справа к этой записи приписываются разряды 10, если нечётно — разряды 01.
3. Полученная запись является двоичной записью искомого числа R. Это число переводится в десятичную систему счисления.

*Пример.* Дано число N = 6. Автомат работает следующим образом.

1. Двоичная запись числа 6: 110.
2. В этой записи две единицы — их количество чётно, поэтому справа приписываются разряды 10: 11010.
3. Полученная запись является двоичной записью числа 26.

Результат работы автомата — число R = 26.

Определите наименьшее число N, после обработки которого автомат получает число R, большее 517.

В ответе запишите это число в десятичной системе счисления.
