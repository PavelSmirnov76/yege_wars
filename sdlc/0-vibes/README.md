# 0 — Входящие и PRD

Самая ранняя стадия. Всё, что приходит, пока не стало структурой, и
единственный PRD, который это вбирает.

Отсюда уходит только требование: когда оно записано в `prd/PRD.md` и на него
ссылается бизнес-задача в `1-business-tasks/`.

## Состав

- `raw/` — входящие по датам: данные извне, черновики нового, находки.
- `prd/` — PRD: замысел продукта, словарь терминов и требования `R{n}`.
