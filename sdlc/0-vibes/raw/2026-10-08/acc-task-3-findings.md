   `summary.json`) считает записи «тест — метка», а не тесты: тест с двумя
   метками входит дважды, SQL-метки — тоже. Прогон `2026-10-08-2a0988a`: 315 —
   это 293 записи Dart на 291 тест и 22 записи SQL. Число тестов Dart — по
   `flutter test`. Источник — сдача; подтверждено по `summary.json`. Скрипт
   конвейера — работа постановщика с одобрения владельца.
2. Тест «пока сессия не проверена, показывается заставка»
   (`test/app/router/app_router_test.dart`) проверяет начало
   [UC-10-P-01](../../../2-specs/use-cases/UC-10-ACTOR-1-EVT-2-ENT-3-SESSION-STARTED-IN-AUTH.md#uc-10-p-01)
   — заставку, пока состояние входа неизвестно, — но метки не имеет. В
   перечень тестов без меток задания TASK-3 он не попал по ошибке постановщика.
   Источник — сдача.
3. Две проверки адреса из `from` в `lib/app/router/app_router.dart` тесты не
   закрепляют: без проверки хоста (`_internalUri`, `uri.hasAuthority`) и без
   проверки служебных путей (`_restoredLocation`, `_servicePaths`) все тесты
   проходят. Примеры из задания (`//example.com`, `/\example.com`, `/login`)
   отсекаются и без них: у первых двух после разбора пустой путь, с `/login`
   вошедшего уводит на главную сам `_guard`. Проверено на копии ветки:
   - без проверки хоста `from=//example.com/task/e24-longest-run` после входа
     открывается как `//example.com/task/e24-longest-run`;
   - без проверки служебных путей `from=/login?from=<адрес>` ведёт на этот
     адрес, а не на главную.

   В коде ветки обе проверки есть, поведение верное. Не закреплено тестом
   адреса с хостом и путём, например `//example.com/task/<slug>`.
