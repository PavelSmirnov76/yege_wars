# Находки при подготовке перевода на конвейер

Записано 2026-10-08 при изучении проекта перед переводом на конвейер (журнал
перевода — `docs/SDLC_ADOPTION.md`). Это не задания: в работу они идут только
проходом конвейера.

- `registration_open` на боевой = `true`: до публичного деплоя его нужно
  закрыть, иначе после выключения подтверждения почты зарегистрируется кто
  угодно.
- История git (33 коммита) чиста: в строках подключения только плейсхолдеры,
  `sb_secret_` — лишь упоминание в комментарии. Полная проверка — перед первым
  push.
- `admin_student_overview` считает по всем 2476 задачам, без фильтра по статусу
  и без пагинации — для задания на админку.
- В боевой базе нет журнала применённых миграций.
- Опубликованная `fipi-2f4c39` — без таблиц-вариантов ответа. Варианты потеряны
  импортом у 4 заданий банка: 3E9C16, 2F4C39, 8DA527, 1A48C1.
- 14 подтверждённых задач банка имеют только картинки условия (13 — номер 1,
  плюс BA5430); 3E9C16 из них публиковать нельзя (варианты потеряны).

  подтверждена. Ответы задач проекта есть только в `supabase/seed/local/`.
- GitHub Pages на бесплатном плане, по документации GitHub, требует публичного
  репозитория — не проверено.
- `lib/core/error/rpc_error.dart` в dartdoc `RpcErrorCodes` отсылает за полным
  списком кодов ошибок к `docs/STATE.md`, а он 2026-10-08 переехал в
  `sdlc/0-vibes/raw/2026-10-08/STATE.md`. Это код продукта: правится заданием,
  когда коды ошибок попадут в спеки.
