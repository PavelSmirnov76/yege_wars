## Критерии готовности MVP — дословно из ТЗ

Без оценки, какие уже выполнены.

- Новый пользователь регистрируется по логину без почты и видит каталог.
- В задаче 24 код `open('24.txt')` читает файл, выводит результат, ответ отправляется и засчитывается.
- Ответ задачи нельзя узнать ни из фронтенда, ни через API с anon key.
- Чужие решения недоступны до своего верного ответа (проверено тестом RLS).
- Бесконечный цикл останавливается кнопкой «Стоп» или по таймауту, интерфейс не зависает.
- Сайт нормально работает на телефоне (ширина 360 px) и на десктопе.
- Админ видит список учеников, открывает любого и просматривает всю историю его попыток с кодом по каждой задаче.
- Ученик не может получить список учеников или чужие попытки через API (проверено тестом RLS).
- CI зелёный, анализатор без предупреждений.
