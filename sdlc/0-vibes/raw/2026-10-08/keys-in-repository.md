# Ключи в репозитории: адрес проекта и публичный ключ

2026-10-08, при проверке безопасности перед первым push.

- В `lib/core/config/env.dart` значения по умолчанию — адрес боевого проекта
  Supabase и его публичный ключ `sb_publishable_…`; в истории git — с коммита
  `48aa800` (2026-09-18). Поэтому экран «Приложение не сконфигурировано» на
  деле недостижим: значения есть всегда.
- Секретного ключа `sb_secret_`, паролей и строк подключения в истории нет
  (проверено по всем коммитам). Локальные доступы — в `supabase/.env.local`,
  он в `.gitignore`.

Решения владельца (журнал перевода, решения 24–27): репозиторий будет
публичным, только код, без публикации сайта; засвеченным считается только
ключ, попавший в git, — значит, публичный ключ перевыпускается, а секретный
остаётся; адрес и ключ уходят из кода в незаливаемую конфигурацию сборки;
историю git не переписывать.
