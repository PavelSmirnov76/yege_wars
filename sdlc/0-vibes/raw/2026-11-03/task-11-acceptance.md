# Наблюдения при приёмке чипов каталога

Дата: 2026-11-03. Локальная release-сборка `task/TASK-11`, `ec9cdc4`,
тестовый Supabase `yege_wars_dev`. Продуктовый фикс касается только
плотности чипов каталога. Следующие наблюдения не исправлялись.

## Длинный заголовок страницы задачи

В [раунде TC-14](../../../6-eval/manual/2026-11-03/TC-14/transcript.md),
[мобильный переход к задаче](../../../6-eval/manual/2026-11-03/TC-14/screenshots/25-mobile-step03.png),
длинный заголовок T=`fipi-dff2f9` в AppBar сокращён многоточием. Полный
заголовок есть в semantics и в условии ниже; переход ведёт к выбранной
задаче. Это наблюдение отдельного экрана, а не установленный дефект
каталога. Глубокая проверка страницы задачи прямо исключена из
[TC-14](../../../6-eval/manual/TC-14-CATALOG-FILTERS.md); её контракт здесь
заново не принимался.

## Сброс поиска

Повторилось прежнее наблюдение: сброс снимает условия запроса и возвращает
полный список, но поле сохраняет текст Q. Кейс явно допускает записать это
отдельно, поскольку UC не задаёт вид поля после сброса. Нового нарушения
контракта по этому наблюдению не установлено.
Предыдущая запись — [находки каталога](../2026-11-02/catalog-manual-findings.md).

## Сверка данных

В журнале реального каталога различаются число задач (140) и число
уникальных названий (134): есть одноимённые задачи. Число уникальных
подписей не следует выдавать за число задач. Перехватчик TC-14 наблюдал
только разрешённые поля каталога, статистики и собственных попыток;
значения user_id, доступы и ответы задач не записывались.

Эти наблюдения не являются заданием на изменение поведения. Новых
продуктовых исправлений помимо принимаемого TASK-11 не выполнялось.
