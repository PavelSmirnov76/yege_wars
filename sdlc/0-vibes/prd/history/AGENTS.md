# История PRD — прежние версии

**Ничего здесь не читать, если работа прямо не требует истории PRD.** Ответ на
«что такое R7?» даёт текущий PRD (закон, «PRD — изменяемый контейнер
замороженных требований»), а чтение этой папки только тратит контекст.

Читать её — только чтобы ответить, почему PRD изменился.

## Именование

```
PRD-{ГГГГ-ММ-ДД}.md
```

Дата, когда версию **сменили**, а не когда её написали. Второй снимок за тот же
день получает суффикс: `PRD-2026-11-02-02.md`.

## У каждой прежней версии есть шапка

Сверху файла, перед исходным текстом:

- **сменён** — дата, когда версия перестала быть текущей;
- **почему** — что изменилось, одной строкой;
- **вход** — папка `raw/<дата>/` или сигнал `9-observation/`, из-за которых
  версия устарела.

Шапка — единственное, что можно добавить. Исходный текст под ней заморожен:
его не исправляют и не причёсывают. Исключение одно, и оно про навигацию, а не
про содержание: при снимке скрипт перебазирует пути ссылок на эту папку.
