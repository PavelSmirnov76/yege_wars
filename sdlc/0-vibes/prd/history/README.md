# История PRD

Прежние версии PRD, по файлу на каждую заменённую.

Отсюда ничего не уходит. Папка отвечает на вопрос *почему PRD изменился*, но
не *что PRD говорит*: на это отвечает только текущий PRD, а устаревшие
требования остаются в нём, чтобы ради ссылки никто сюда не заглядывал.

Файл назван датой замены (`PRD-2026-10-08.md`) и открывается шапкой: когда
версию сменили, почему и какой вход к этому привёл.
