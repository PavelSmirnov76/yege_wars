## Зачем

Репозиторий станет публичным. В `lib/core/config/env.dart` по умолчанию
записаны адрес боевого проекта Supabase и его публичный ключ, поэтому они
уйдут в открытый доступ, а экран «Приложение не сконфигурировано» на деле
недостижим. По R15 значения приходят только из параметров сборки
(`--dart-define`), а в коде их нет; по R16 без них приложение показывает этот
экран. Задание убирает значения по умолчанию.

Вне задания: перевыпуск публичного ключа в панели Supabase и запись нового
значения в `supabase/.env.local` — это делает владелец после приёмки. История
git не переписывается.

Прочитать перед работой: `CLAUDE.md`; UC-12 и FIG-9 из «Основания»;
`lib/core/config/env.dart`, `lib/app/bootstrap.dart`,
`lib/app/not_configured_app.dart`, `test/app/bootstrap_test.dart`; `README.md`,
раздел «Локальный запуск». Сдача — по `sdlc/5-results/AGENTS.md`, прочитать до
начала работы; номер сдачи — `python3 -m sdlc_tool next RESULT TASK-2`.

## Часть 1. Локально

### 1.1. Убрать значения по умолчанию

В `env.dart` удалить `_defaultSupabaseUrl` и `_defaultSupabaseAnonKey`;
`supabaseUrl` и `supabaseAnonKey` — `String.fromEnvironment` без значений по
умолчанию. Doc-комментарий класса — по R15: значения только из параметров
сборки, локально — из `supabase/.env.local`. Поведение `bootstrap` и заглушки не
менять.

  параметров сборки `Env.supabaseUrl` и `Env.supabaseAnonKey` пусты,
  `Env.isConfigured` — `false`. Без правки 1.1 он падает.
- Метки путей UC-12 — тестам, которые их проверяют. P-03 (не удалось
  подключиться) и P-01 (запуск с параметрами) — тестом, если его можно
