# 4 — Задания

Задание — промт исполнителю. Отдельная сессия агента выполняет его по фразе
«выполни sdlc/4-tasks/TASK-{n}-{TITLE}.md» и знает о проекте только то, что
есть в репозитории. Задание выводится из спек и, если задевает экраны, из
дизайна.

Задание входит в стадию, когда его спеки (и дизайн, если он нужен) уже есть, и
закрывается, когда его последняя приёмка — «принято».

`INDEX.md` показывает по каждому заданию: какие пути UC оно покрывает, его
сдачи и приёмки.
