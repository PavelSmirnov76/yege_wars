# TOKEN-4: Радиусы

Скругления, в логических пикселях.

| Токен | Значение | Назначение |
|---|---|---|
| <a id="sm"></a>`AppRadius.sm` | `6` | чипы, бейджи, мелкие кнопки |
| <a id="md"></a>`AppRadius.md` | `10` | контролы: кнопки, поля ввода, меню |
| <a id="lg"></a>`AppRadius.lg` | `16` | контейнеры: карточки, диалоги, панели |
| <a id="full"></a>`AppRadius.full` | `999` | круглая форма: пилюли, аватары |
