# Дизайн-система

Токены (`TOKEN-{n}`) — цвета, типографика, отступы, радиусы, брейкпоинты,
тап-цели — и компоненты (`COMP-{n}`): их варианты, состояния и токены. Экраны
`3-design/FIG-*` ссылаются сюда, а не на значения; код темы и виджеты несут
метки отсюда.

Артефакт покидает папку, когда на него ссылается экран или задание.

Правила — в [AGENTS.md](AGENTS.md).
