# COMP-18: Последние попытки в профиле

## Варианты

Список до десяти строк. Каждая строка содержит название задачи, номер КЕГЭ
либо «Без номера КЕГЭ», текст «Верно» или «Неверно» и локальное время в
формате ДД.ММ ЧЧ:ММ. Формат соответствует истории попыток страницы задачи.
Длинное название переносится, метаданные на узком экране располагаются
следующей строкой. При пустом списке показано «Попыток пока нет».

## Состояния

Обычное состояние даёт выбрать строку и открыть задачу. Для мыши виден
штатный Material hover, для клавиатуры — фокус и активация Enter/Space.
Нажатие даёт штатный отклик. Семантическая подпись содержит название,
номер, вердикт и время. Строка занимает доступную ширину.

- Типографика — `AppTypography.textTheme`, [TOKEN-2](TOKEN-2-TYPOGRAPHY.md#text-theme),
  `bodyLarge` для названия и `bodyMedium` для метаданных.
- Основной и вторичный текст — [TOKEN-7](TOKEN-7-COLOR.md#text-primary)
  и [TOKEN-7](TOKEN-7-COLOR.md#text-secondary).
- «Верно» — [TOKEN-7](TOKEN-7-COLOR.md#success), «Неверно» —
  [TOKEN-7](TOKEN-7-COLOR.md#danger), с текстовой подписью каждого вердикта.
- Внутренний отступ — `AppSpacing.lg`, [TOKEN-3](TOKEN-3-SPACING.md#lg),
  между названием и метаданными — `AppSpacing.sm`, [TOKEN-3](TOKEN-3-SPACING.md#sm).
- Минимальная область активации и фокус — [TOKEN-6](TOKEN-6-TAP.md).
- Контейнер — поверхность [TOKEN-7](TOKEN-7-COLOR.md#surface),
  радиус `AppRadius.lg`, [TOKEN-4](TOKEN-4-RADIUS.md#lg).
