# TOKEN-5: Брейкпоинты

Ширина окна, в логических пикселях: телефон — до 600, планшет — до 1024, дальше десктоп.

| Токен | Значение | Назначение |
|---|---|---|
| <a id="mobile-max"></a>`AppBreakpoints.mobileMax` | `600` | максимальная ширина мобильной раскладки |
| <a id="tablet-max"></a>`AppBreakpoints.tabletMax` | `1024` | максимальная ширина планшетной раскладки |
