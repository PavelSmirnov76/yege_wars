# COMP-11: Блок кода

Код только для чтения с подсветкой Python.

## Варианты

- **Python** — язык не указан или указан как `python`, `py`, `python3`:
  подсветка теми же цветами, что у [COMP-8](COMP-8-CODE-EDITOR.md).
- **Другой язык** — без подсветки, цветом `AppColors.textPrimary` — [TOKEN-1](obsolete/TOKEN-1-COLOR.md#text-primary).

## Состояния

Обычное: текст можно выделить и скопировать; длинные строки прокручиваются
вбок.

## Размеры и токены

- Шрифт: `AppTypography.code` — [TOKEN-2](TOKEN-2-TYPOGRAPHY.md#code).
- Фон: `AppColors.codeBackground` — [TOKEN-1](obsolete/TOKEN-1-COLOR.md#code-background); рамка — `AppColors.border` — [TOKEN-1](obsolete/TOKEN-1-COLOR.md#border).
- Отступ внутри: `AppSpacing.md` — [TOKEN-3](TOKEN-3-SPACING.md#md); скругление — `AppRadius.md` — [TOKEN-4](TOKEN-4-RADIUS.md#md).
