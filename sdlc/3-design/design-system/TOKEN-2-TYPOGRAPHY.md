# TOKEN-2: Типографика

Inter для интерфейса, JetBrains Mono для кода.

| Токен | Значение | Назначение |
|---|---|---|
| <a id="text-theme"></a>`AppTypography.textTheme` | Inter, шкала Material 2021, цвет `AppColors.textPrimary` | весь текст интерфейса |
| <a id="code"></a>`AppTypography.code` | JetBrains Mono | код: примеры, редактор, решения |
| <a id="default-code-font-size"></a>`AppTypography._defaultCodeFontSize` | `14` | размер шрифта кода по умолчанию |
| <a id="code-line-height"></a>`AppTypography._codeLineHeight` | `1.5` | межстрочный интервал кода |
