# TOKEN-6: Тап-цели и фокус

Доступность контролов.

| Токен | Значение | Назначение |
|---|---|---|
| <a id="min-tap-target"></a>`AppTheme._minTapTarget` | `44` | минимальный размер тап-цели кнопок, в логических пикселях |
| <a id="focused-border-width"></a>`AppTheme._focusedBorderWidth` | `2` | толщина рамки поля ввода в фокусе |
