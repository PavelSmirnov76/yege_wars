# 3 — Дизайн

Дизайн текстом, выведенный из спек `2-specs/`: дизайн-система и экраны. Figma
нет — внешний вид задают эти файлы, а воплощает код темы `lib/app/theme/` и
виджеты.

Артефакт покидает стадию, когда на него ссылается задание в `4-tasks/`.

## Состав

- `design-system/` — токены (`TOKEN-{n}`) и компоненты (`COMP-{n}`).
- `FIG-{n}-{SCREEN}.md` — экраны, прямо в этой папке.

Дизайн-систему уже построенного снимают с кода частями, вместе с проходами «как
построено».

Правила экранов — в [AGENTS.md](AGENTS.md), токенов и компонентов — в
[design-system/AGENTS.md](design-system/AGENTS.md).
