# UC-18: Ответ из вывода

**Основание:** [R31](../../0-vibes/prd/PRD.md#r31), [BT-11](../../1-business-tasks/planning/BT-11-PLANNING-ANSWER-CHECK.md), [MOD-6](../modules/MOD-6-SUBMISSION.md).

**Актор, событие, сущность:** [ACTOR-4](../actors/ACTOR-4-STUDENT-IN-SUBMISSION.md), [EVT-15](../events/EVT-15-OUTPUT-TAKEN-IN-SUBMISSION.md), [ENT-9](../entities/ENT-9-RUN-IN-EDITOR.md).

## Триггер

Пользователь нажимает «Взять из вывода».

## Предусловия

В выводе последнего запуска есть непустая строка — иначе кнопки нет.

## Пути

### <a id="uc-18-p-01"></a>UC-18-P-01 — ответ подставлен

Для формата «несколько чисел» в поле ответа встают все непустые строки вывода
без пробельных краёв через один пробел: таблица, напечатанная по строкам,
становится ответом в одну строку. Для остальных форматов — последняя непустая
строка вывода без пробельных краёв.

**Исход:** UC-18-O-01 — поле ответа заполнено

## Постусловия

Ответ не отправлен: отправляет его пользователь.
