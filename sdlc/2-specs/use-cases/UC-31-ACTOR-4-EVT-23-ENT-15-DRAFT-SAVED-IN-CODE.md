# UC-31: Черновик кода

**Актор, событие, сущность:** [ACTOR-4](../actors/ACTOR-4-STUDENT-IN-SUBMISSION.md), [EVT-23](../events/EVT-23-DRAFT-SAVED-IN-CODE.md), [ENT-15](../entities/ENT-15-DRAFT-IN-CODE.md).

## Триггер

Пользователь открывает задачу, правит код в редакторе, нажимает «Запустить»
или «Отправить ответ» либо уходит со страницы задачи.

## Предусловия

Пользователь вошёл.

## Пути

### <a id="uc-31-p-01"></a>UC-31-P-01 — черновик сохранён

Через 1 с после последней правки, а также сразу при нажатии «Запустить» или
«Отправить ответ» и при уходе со страницы задачи код записывается в базу — для
этого пользователя и этой задачи. При открытии задачи на любом устройстве
черновик стоит в поле кода. После отправки ответа черновик остаётся.

**Исход:** UC-31-O-01 — черновик сохранён

### <a id="uc-31-p-02"></a>UC-31-P-02 — черновик удалён

Код из одних пробельных символов удаляет черновик: при следующем открытии
задачи поле кода пустое.

**Исход:** UC-31-O-02 — черновик удалён

### <a id="uc-31-p-03"></a>UC-31-P-03 — сбой сохранения

Черновик не записан; экран ничего не показывает. Следующее сохранение — после
правки, по кнопке или при уходе со страницы — пишет код снова.

**Исход:** UC-31-O-03 — черновик не сохранён

### <a id="uc-31-p-04"></a>UC-31-P-04 — черновик не загрузился

Черновик загружается вместе с задачей. Если он не загрузился, вместо страницы
задачи — сообщение об ошибке и кнопка «Повторить», как при сбое загрузки
задачи.

**Исход:** UC-31-O-04 — задача не открыта

## Постусловия

Черновик видит и меняет только его автор. В браузере код не хранится.
