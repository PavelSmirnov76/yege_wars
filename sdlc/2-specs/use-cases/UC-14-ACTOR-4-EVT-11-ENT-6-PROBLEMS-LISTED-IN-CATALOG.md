# UC-14: Каталог задач

**Основание:** [R18](../../0-vibes/prd/PRD.md#r18), [R19](../../0-vibes/prd/PRD.md#r19), [R20](../../0-vibes/prd/PRD.md#r20), [R23](../../0-vibes/prd/PRD.md#r23), [BT-8](../../1-business-tasks/planning/BT-8-PLANNING-CATALOG.md), [MOD-4](../modules/MOD-4-CATALOG.md).

**Актор, событие, сущность:** [ACTOR-4](../actors/ACTOR-4-STUDENT-IN-SUBMISSION.md), [EVT-11](../events/EVT-11-CATALOG-OPENED-IN-CATALOG.md), [ENT-6](../entities/ENT-6-PROBLEM-IN-CATALOG.md).

## Триггер

Пользователь открывает главную или меняет отбор задач.

## Предусловия

Пользователь вошёл.

## Пути

### <a id="uc-14-p-01"></a>UC-14-P-01 — задачи есть

Опубликованные задачи идут по номеру КЕГЭ по возрастанию, внутри номера — по
названию; над каждой группой — «Задание N», задачи без номера — группой «Без
номера» в конце. Карточка: название; состояние решения — «Решено» или «Есть
попытки», у не начатой задачи метки нет; сложность — «Простая», «Средняя» или
«Сложная»; доля решивших — «Решили N%» или «Ещё никто не решал». Нажатие на
карточку открывает страницу задачи.

**Исход:** UC-14-O-01 — показаны задачи

### <a id="uc-14-p-02"></a>UC-14-P-02 — отбор

Чипы номеров КЕГЭ — только тех, по которым есть задачи; чипы сложности и
состояния решения; повторное нажатие снимает условие. Поиск по части названия
срабатывает через 300 мс после ввода. Когда задано хоть одно условие, видна
кнопка «Сбросить фильтры». По состоянию решения отбирает клиент, по остальным
условиям — база. Если номера не загрузились, чипов номеров нет, а каталог
работает.

**Исход:** UC-14-O-02 — показаны отобранные задачи

### <a id="uc-14-p-03"></a>UC-14-P-03 — задач нет

Без условий отбора — «Задач пока нет»; с условиями — «По этим условиям задач
нет».

**Исход:** UC-14-O-03 — показано, что задач нет

### <a id="uc-14-p-04"></a>UC-14-P-04 — сбой связи или сервера

Сообщение об ошибке и кнопка «Повторить».

**Исход:** UC-14-O-04 — каталог не загружен

## Постусловия

Данные не меняются.
