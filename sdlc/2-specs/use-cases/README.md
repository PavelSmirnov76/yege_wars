# Use-cases

**Как это разыгрывается**: сквозные сценарии, где актор, событие-триггер и
главная сущность приводят к результату.

Каждый UC — отдельный файл; его имя несёт главного актора, событие, сущность и
исход основного пути. Листинг папки сам говорит, кто что сделал с какой
сущностью и чем кончилось.

Внутри UC — пути и исходы: `UC-{n}-P-{nn}` → `UC-{n}-O-{nn}`, один к одному.
Путь — единица проверки: тесты метятся путями, и `6-eval/DASHBOARD.md`
показывает вердикт по каждому.

Правила — в [AGENTS.md](AGENTS.md).
