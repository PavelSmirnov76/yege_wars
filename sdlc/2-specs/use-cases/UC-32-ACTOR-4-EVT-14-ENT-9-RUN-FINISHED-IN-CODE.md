# UC-32: Запуск программы

## Триггер

Пользователь нажимает «Запустить» или Ctrl/Cmd+Enter в поле кода.

## Предусловия

Страница задачи открыта, программа не выполняется.

## Пути

### <a id="uc-32-p-01"></a>UC-32-P-01 — программа завершилась

«Запустить» сначала сохраняет черновик. Пока запуск не закончился — и пока
загружается среда Python, и пока выполняется программа, — «Запустить»
недоступна, а «Стоп» доступна. Если среда ещё не загружена — первый запуск
на вкладке и первый после «Стоп» или таймаута, — пока она загружается, строка
состояния — «Загружаю Python — это разовая загрузка, потерпите»; во время
выполнения — «Выполняется…». Программа открывает файлы задачи по их именам и
читает ввод из поля «Ввод (stdin)». Вывод — в консоли, строка состояния —
«Готово за N с», вместе с загрузкой среды. Вывод длиннее 20 000 символов
обрезается с припиской, сколько скрыто.

**Исход:** UC-32-O-01 — показан вывод

### <a id="uc-32-p-02"></a>UC-32-P-02 — ошибка в программе

Трассировка — в консоли красным, после вывода; строка состояния — «Программа
завершилась ошибкой».

**Исход:** UC-32-O-02 — показана ошибка программы

### <a id="uc-32-p-03"></a>UC-32-P-03 — «Стоп»

Прерывается выполнение программы или загрузка среды; строка состояния —
«Остановлено». Следующий запуск загружает среду заново.

**Исход:** UC-32-O-03 — запуск остановлен

### <a id="uc-32-p-04"></a>UC-32-P-04 — дольше 60 секунд

Программа останавливается сама: в консоли — «Программа не уложилась в 60 с и
была остановлена.», строка состояния — «Не уложилось в отведённое время».
Время считается с нажатия, вместе с загрузкой среды.

**Исход:** UC-32-O-04 — запуск остановлен по времени

### <a id="uc-32-p-05"></a>UC-32-P-05 — Python не запустился

Причина — в консоли красным: например, «Не удалось загрузить Python ни с
одного адреса» со списком адресов и ошибок или «Не удалось запустить среду
Python. Обновите страницу.». Следующий запуск пробует снова.

**Исход:** UC-32-O-05 — среда не запустилась

## Постусловия

Вывод последнего запуска виден до следующего. Интерфейс не зависает ни в одном
пути. В базу пишется только черновик.
