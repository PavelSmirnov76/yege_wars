# UC-41: Свой прогресс в профиле

**Основание:** [R51](../../0-vibes/prd/PRD.md#r51), [R52](../../0-vibes/prd/PRD.md#r52), [R53](../../0-vibes/prd/PRD.md#r53), [R55](../../0-vibes/prd/PRD.md#r55), [R46](../../0-vibes/prd/PRD.md#r46), [BT-22](../../1-business-tasks/planning/BT-22-PLANNING-PROFILE-PROGRESS.md), [MOD-10](../modules/MOD-10-PROGRESS.md).

**Актор, событие, сущность:** [ACTOR-2](../actors/ACTOR-2-USER-IN-AUTH.md), [EVT-25](../events/EVT-25-PROGRESS-OPENED-IN-PROGRESS.md), [ENT-18](../entities/ENT-18-PROGRESS-SUMMARY-IN-PROGRESS.md).

## Триггер

Пользователь открывает профиль, в том числе возвращается в существующую ветку.

## Предусловия

Пользователь вошёл. Данные загружаются для id текущего аккаунта.

## Пути

### <a id="uc-41-p-01"></a>UC-41-P-01 — прогресс и попытки

Во время запросов показана загрузка. После успеха обоих запросов показаны
общее число решённых и доступных задач, строки по номерам и последние
попытки согласно контракту сущности. Числа учитывают уникальные задачи,
повторные решения, скрытие/повторную публикацию и задачи без номера.
Обновление после отправки ответа, повторное открытие и смена аккаунта
используют актуальные данные текущего пользователя. Результаты устаревших
запросов отбрасываются. На экране администратора показаны его свои данные.

**Исход:** UC-41-O-01 — свой прогресс показан

### <a id="uc-41-p-02"></a>UC-41-P-02 — попыток нет

Опубликованные задачи есть, своих попыток по ним нет. Число решённых равно
нулю, строки содержат доступное количество. Вместо списка попыток показано
«Попыток пока нет».

**Исход:** UC-41-O-02 — показан начальный прогресс

### <a id="uc-41-p-03"></a>UC-41-P-03 — опубликованных задач нет

Список прогресса и последние попытки пусты. Общая сводка содержит 0 из 0,
вместо строк показано «Пока нет опубликованных задач», вместо попыток —
«Попыток пока нет». Деления на ноль при расчёте индикатора нет.

**Исход:** UC-41-O-03 — показано отсутствие доступных задач

### <a id="uc-41-p-04"></a>UC-41-P-04 — отказ загрузки

Хотя бы один запрос завершился ошибкой. Вместо содержимого прогресса
показаны сообщение ошибки и «Повторить». Автоматического повтора нет.
Логин, роль, выход и навигация доступны. Ошибка не показывается как нули.

**Исход:** UC-41-O-04 — показан отказ загрузки прогресса

### <a id="uc-41-p-05"></a>UC-41-P-05 — восстановление загрузки

После отказа пользователь нажимает «Повторить». Оба запроса выполняются
заново с текущим id, видна загрузка. После успеха показаны новые данные
либо соответствующее пустое состояние. При новом отказе доступен тот же
повтор, как в пути отказа.

**Исход:** UC-41-O-05 — загрузка прогресса восстановлена

## Постусловия

Запросы только читают. Сводка на экране принадлежит текущему аккаунту.
