# UC-33: Публикация решения

supersedes: [UC-20](obsolete/UC-20-ACTOR-4-EVT-17-ENT-11-SOLUTION-PUBLISHED-IN-SUBMISSION.md)

**Основание:** [R33](../../0-vibes/prd/PRD.md#r33), [R47](../../0-vibes/prd/PRD.md#r47), [BT-12](../../1-business-tasks/planning/BT-12-PLANNING-SOLUTIONS.md), [BT-19](../../1-business-tasks/planning/BT-19-PLANNING-PUBLICATION-FAILURE.md), [MOD-6](../modules/MOD-6-SUBMISSION.md).

**Актор, событие, сущность:** [ACTOR-4](../actors/ACTOR-4-STUDENT-IN-SUBMISSION.md), [EVT-17](../events/EVT-17-PUBLICATION-SWITCHED-IN-SUBMISSION.md), [ENT-11](../entities/ENT-11-ATTEMPT-IN-SUBMISSION.md).

## Триггер

Пользователь нажимает «Опубликовать решение» или «Не сейчас» в блоке «Задача
решена!» либо переключает «Опубликовано» у своей верной попытки.

## Предусловия

У пользователя есть верная попытка по задаче.

## Пути

### <a id="uc-33-p-01"></a>UC-33-P-01 — решение опубликовано

Попытка опубликована, время публикации записано; блок «Задача решена!»
скрывается, переключатель «Опубликовано» у попытки включён. Решение видят
другие, кто решил задачу верно.

**Исход:** UC-33-O-01 — решение опубликовано

### <a id="uc-33-p-02"></a>UC-33-P-02 — снято с публикации

Переключатель выключен; публикация и её время сняты; другим решение больше не
видно.

**Исход:** UC-33-O-02 — решение снято с публикации

### <a id="uc-33-p-03"></a>UC-33-P-03 — «Не сейчас»

Блок «Задача решена!» скрывается; попытка не опубликована, опубликовать её
можно позже переключателем.

**Исход:** UC-33-O-03 — решение не опубликовано

### <a id="uc-33-p-04"></a>UC-33-P-04 — отказ или сбой

База отказывает в публикации чужой попытки — «Публиковать можно только свои
решения.» — и неверной — «Опубликовать можно только верное решение.»; на
экране у таких попыток переключателя нет. Если публикация из блока «Задача
решена!» не удалась — отказ или сбой связи, — блок остаётся, под его
кнопками — текст ошибки, и опубликовать можно снова. Если не удалось
переключить «Опубликовано», переключатель остаётся прежним, а внизу экрана —
сообщение с текстом ошибки.

**Исход:** UC-33-O-04 — публикация не изменилась

## Постусловия

Код и ответ попытки не меняются.
