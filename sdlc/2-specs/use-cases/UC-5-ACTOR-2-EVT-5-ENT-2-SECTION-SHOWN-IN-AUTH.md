# UC-5: Раздел администратора

**Основание:** [R11](../../0-vibes/prd/PRD.md#r11), [BT-3](../../1-business-tasks/planning/BT-3-PLANNING-ROLE-ACCESS.md), [MOD-1](../modules/MOD-1-AUTH.md).

**Актор, событие, сущность:** [ACTOR-2](../actors/ACTOR-2-USER-IN-AUTH.md), [EVT-5](../events/EVT-5-ADMIN-SECTION-OPENED-IN-AUTH.md), [ENT-2](../entities/ENT-2-PROFILE-IN-AUTH.md).

## Триггер

Пользователь открывает адрес `/admin` или пункт меню «Админка».

## Предусловия

Пользователь вошёл.

## Пути

### <a id="uc-5-p-01"></a>UC-5-P-01 — администратор

Пункт «Админка» есть в меню, экран раздела открывается.

**Исход:** UC-5-O-01 — раздел открыт

### <a id="uc-5-p-02"></a>UC-5-P-02 — ученик

Пункта «Админка» в меню нет; адрес `/admin` уводит на главную.

**Исход:** UC-5-O-02 — раздел не открыт

## Постусловия

Изменений нет. Клиентская проверка — для удобства; защищает база.
