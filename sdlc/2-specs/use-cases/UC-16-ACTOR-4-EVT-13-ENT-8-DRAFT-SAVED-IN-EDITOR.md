## Предусловия

Страница задачи открыта.

## Пути

### <a id="uc-16-p-01"></a>UC-16-P-01 — черновик сохранён

Через 600 мс после правки код записывается на устройство для этой задачи; код
из одних пробельных символов удаляет черновик. При следующем открытии задачи
на этом устройстве черновик подставляется в пустое поле кода.

**Исход:** UC-16-O-01 — черновик сохранён

## Постусловия

В базу код не уходит, пока его не отправят вместе с ответом.
