## Триггер

Пользователь открывает страницу задачи — раздел или вкладку «Решения».

## Предусловия

Пользователь вошёл.

## Пути

### <a id="uc-35-p-01"></a>UC-35-P-01 — задача решена

Опубликованные решения других, свежие первыми: «логин, ДД.ММ ЧЧ:ММ» и код с
подсветкой Python. Своих решений в списке нет.

**Исход:** UC-35-O-01 — показаны решения

### <a id="uc-35-p-02"></a>UC-35-P-02 — задача не решена

«Решения других откроются после твоего верного ответа». База сама не отдаёт
чужих попыток по задаче, пока у пользователя нет своей верной попытки по ней, —
ни опубликованных, ни остальных.

**Исход:** UC-35-O-02 — решения закрыты

### <a id="uc-35-p-03"></a>UC-35-P-03 — решений нет

Задача решена, но опубликованных решений других нет: «Пока никто не
опубликовал своё решение».

**Исход:** UC-35-O-03 — показано, что решений нет

### <a id="uc-35-p-04"></a>UC-35-P-04 — сбой загрузки

Вместо списка — сообщение об ошибке и кнопка «Повторить».

**Исход:** UC-35-O-04 — решения не загружены

## Постусловия

Данные не меняются.
