# UC-11: Выход

supersedes: [UC-3](UC-3-ACTOR-2-EVT-3-ENT-3-SESSION-ENDED-IN-AUTH.md)

**Основание:** [R8](../../../0-vibes/prd/PRD.md#r8), [BT-2](../../../1-business-tasks/planning/BT-2-PLANNING-SIGN-IN.md), [MOD-1](../../modules/MOD-1-AUTH.md).

**Актор, событие, сущность:** [ACTOR-2](../../actors/ACTOR-2-USER-IN-AUTH.md), [EVT-3](../../events/EVT-3-SIGNED-OUT-IN-AUTH.md), [ENT-3](../../entities/ENT-3-SESSION-IN-AUTH.md).

## Триггер

Пользователь нажимает «Выйти» в профиле — в этой вкладке браузера или в другой.

## Предусловия

Пользователь вошёл.

## Пути

### <a id="uc-11-p-01"></a>UC-11-P-01 — выход

Сессия завершается, приложение показывает экран входа.

**Исход:** UC-11-O-01 — сессия завершена

### <a id="uc-11-p-02"></a>UC-11-P-02 — ошибка выхода

Сессия не завершается, пользователь остаётся вошедшим; ошибка показывается сообщением внизу экрана.

**Исход:** UC-11-O-02 — выход не выполнен

### <a id="uc-11-p-03"></a>UC-11-P-03 — выход в другой вкладке

Пользователь вышел в другой вкладке браузера: эта вкладка тоже переходит на экран входа.

**Исход:** UC-11-O-03 — сессия завершена во всех вкладках

## Постусловия

После выхода состояние входа — «не вошёл»; при ошибке выхода — прежнее.
