# UC-22: Чужие решения

**Основание:** [R34](../../../0-vibes/prd/PRD.md#r34), [BT-12](../../../1-business-tasks/planning/BT-12-PLANNING-SOLUTIONS.md), [MOD-6](../../modules/MOD-6-SUBMISSION.md).

**Актор, событие, сущность:** [ACTOR-4](../../actors/ACTOR-4-STUDENT-IN-SUBMISSION.md), [EVT-12](../../events/EVT-12-PROBLEM-OPENED-IN-CATALOG.md), [ENT-11](../../entities/ENT-11-ATTEMPT-IN-SUBMISSION.md).

## Триггер

Пользователь открывает страницу задачи — раздел или вкладку «Решения».

## Предусловия

Пользователь вошёл.

## Пути

### <a id="uc-22-p-01"></a>UC-22-P-01 — задача решена

Опубликованные решения других, свежие первыми: «логин, ДД.ММ ЧЧ:ММ» и код с
подсветкой Python. Своих решений в списке нет.

**Исход:** UC-22-O-01 — показаны решения

### <a id="uc-22-p-02"></a>UC-22-P-02 — задача не решена

«Решения других откроются после твоего верного ответа». База сама не отдаёт
чужих попыток по задаче, пока у пользователя нет своей верной попытки по ней, —
ни опубликованных, ни остальных.

**Исход:** UC-22-O-02 — решения закрыты

### <a id="uc-22-p-03"></a>UC-22-P-03 — решений нет

Задача решена, но опубликованных решений других нет: «Пока никто не
опубликовал своё решение».

**Исход:** UC-22-O-03 — показано, что решений нет

### <a id="uc-22-p-04"></a>UC-22-P-04 — сбой загрузки

Вместо списка — индикатор загрузки, сообщения об ошибке нет.

**Исход:** UC-22-O-04 — решения не загружены

## Постусловия

Данные не меняются.
