# UC-25: Справочник

**Основание:** [R35](../../../0-vibes/prd/PRD.md#r35), [R36](../../../0-vibes/prd/PRD.md#r36), [R38](../../../0-vibes/prd/PRD.md#r38), [BT-13](../../../1-business-tasks/planning/BT-13-PLANNING-REFERENCE.md), [MOD-7](../../modules/MOD-7-REFERENCE.md).

**Актор, событие, сущность:** [ACTOR-4](../../actors/ACTOR-4-STUDENT-IN-SUBMISSION.md), [EVT-20](../../events/EVT-20-REFERENCE-OPENED-IN-REFERENCE.md), [ENT-12](../../entities/ENT-12-ARTICLE-IN-REFERENCE.md).

## Триггер

Пользователь открывает `/reference` — пунктом «Справочник» или по ссылке.

## Предусловия

Пользователь вошёл.

## Пути

### <a id="uc-25-p-01"></a>UC-25-P-01 — статьи есть

Статьи идут по уровню — базовый, средний, продвинутый, — внутри уровня по
названию. Карточка: название, описание, уровень, время чтения «N мин», до
четырёх номеров КЕГЭ «№ N» и «…», если номеров больше, до трёх тегов. Ученику
база отдаёт только опубликованные статьи, администратору — и неопубликованные,
без пометки. Нажатие на карточку открывает статью.

**Исход:** UC-25-O-01 — показаны статьи

### <a id="uc-25-p-02"></a>UC-25-P-02 — отбор

Чипы уровня — «Базовый», «Средний», «Продвинутый»; чипы номеров «№ N» и тегов
— только тех, что есть у статей справочника; повторное нажатие снимает
условие, по каждому признаку — одно значение. Поиск по части названия или
описания срабатывает через 300 мс после ввода. Отбирает база. Когда задано
хоть одно условие, видна кнопка «Сбросить фильтры»: она снимает все условия и
строку поиска, но текст в поле поиска остаётся. Если значения фильтров не
загрузились, чипов номеров и тегов нет до конца сессии, а список работает.

**Исход:** UC-25-O-02 — показаны отобранные статьи

### <a id="uc-25-p-03"></a>UC-25-P-03 — статей нет

Без условий — «В справочнике пока нет статей»; с условиями — «По этим
условиям ничего не нашлось».

**Исход:** UC-25-O-03 — показано, что статей нет

### <a id="uc-25-p-04"></a>UC-25-P-04 — сбой связи или сервера

Пока приложение повторяет запрос — до 10 раз, около 40 секунд, — индикатор
загрузки; затем сообщение об ошибке и кнопка «Повторить».

**Исход:** UC-25-O-04 — статьи не загружены

## Постусловия

Данные не меняются.
