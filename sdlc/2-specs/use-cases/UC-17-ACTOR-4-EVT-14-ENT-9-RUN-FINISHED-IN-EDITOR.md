# UC-17: Запуск программы

**Основание:** [R24](../../0-vibes/prd/PRD.md#r24), [R25](../../0-vibes/prd/PRD.md#r25), [BT-10](../../1-business-tasks/planning/BT-10-PLANNING-RUN.md), [MOD-5](../modules/MOD-5-EDITOR.md).

**Актор, событие, сущность:** [ACTOR-4](../actors/ACTOR-4-STUDENT-IN-SUBMISSION.md), [EVT-14](../events/EVT-14-RUN-STARTED-IN-EDITOR.md), [ENT-9](../entities/ENT-9-RUN-IN-EDITOR.md).

## Триггер

Пользователь нажимает «Запустить» или Ctrl/Cmd+Enter в поле кода.

## Предусловия

Страница задачи открыта, программа не выполняется.

## Пути

### <a id="uc-17-p-01"></a>UC-17-P-01 — программа завершилась

Если среда Python ещё не загружена — первый запуск на вкладке и первый после
«Стоп» или таймаута, — до конца запуска строка состояния — «Загружаю Python —
это разовая загрузка, потерпите»: кнопка «Запустить» доступна, «Стоп» —
нет. Если среда загружена, во время выполнения — «Выполняется…»: «Запустить»
недоступна, «Стоп» доступна. Программа открывает файлы задачи по их именам и
читает ввод из поля «Ввод (stdin)». Вывод — в консоли, строка состояния —
«Готово за N с», вместе с загрузкой среды. Вывод длиннее 20 000 символов
обрезается с припиской, сколько скрыто.

**Исход:** UC-17-O-01 — показан вывод

### <a id="uc-17-p-02"></a>UC-17-P-02 — ошибка в программе

Трассировка — в консоли красным, после вывода; строка состояния — «Программа
завершилась ошибкой».

**Исход:** UC-17-O-02 — показана ошибка программы

### <a id="uc-17-p-03"></a>UC-17-P-03 — «Стоп»

Кнопка доступна, когда среда уже загружена. Выполнение прерывается; строка
состояния — «Остановлено». Следующий запуск загружает среду заново.

**Исход:** UC-17-O-03 — запуск остановлен

### <a id="uc-17-p-04"></a>UC-17-P-04 — дольше 60 секунд

Программа останавливается сама: в консоли — «Программа не уложилась в 60 с и
была остановлена.», строка состояния — «Не уложилось в отведённое время».
Время считается с нажатия, вместе с загрузкой среды. Пока среда
загружается, только так останавливается зациклившаяся программа.

**Исход:** UC-17-O-04 — запуск остановлен по времени

### <a id="uc-17-p-05"></a>UC-17-P-05 — Python не запустился

Причина — в консоли красным: например, «Не удалось загрузить Python ни с
одного адреса» со списком адресов и ошибок или «Не удалось запустить среду
Python. Обновите страницу.». Следующий запуск пробует снова.

**Исход:** UC-17-O-05 — среда не запустилась

## Постусловия

Вывод последнего запуска виден до следующего. Интерфейс не зависает ни в одном
пути. В базу ничего не пишется.
