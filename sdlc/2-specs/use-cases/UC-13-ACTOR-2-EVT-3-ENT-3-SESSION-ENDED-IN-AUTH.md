# UC-13: Выход и конец сессии

## Триггер

Пользователь нажимает «Выйти» в профиле — в этой вкладке браузера или в другой —
или сессия заканчивается сама, пока страница открыта.

## Предусловия

Пользователь вошёл.

## Пути

### <a id="uc-13-p-01"></a>UC-13-P-01 — выход

Сессия завершается, приложение показывает экран входа. Адрес страницы, с которой пользователь вышел, не запоминается: следующий вход открывает главную.

**Исход:** UC-13-O-01 — сессия завершена

### <a id="uc-13-p-02"></a>UC-13-P-02 — ошибка выхода

Сессия не завершается, пользователь остаётся вошедшим; ошибка показывается сообщением внизу экрана.

**Исход:** UC-13-O-02 — выход не выполнен

### <a id="uc-13-p-03"></a>UC-13-P-03 — выход в другой вкладке или конец сессии

Пользователь вышел в другой вкладке браузера или сессия закончилась сама: эта вкладка тоже переходит на экран входа. Адрес страницы не запоминается: следующий вход открывает главную.

**Исход:** UC-13-O-03 — сессия завершена во всех вкладках

## Постусловия

После выхода состояние входа — «не вошёл», адрес страницы не запомнен; при
ошибке выхода — прежнее.
