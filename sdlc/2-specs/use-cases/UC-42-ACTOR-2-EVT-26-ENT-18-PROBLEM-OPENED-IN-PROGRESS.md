# UC-42: Задача из последней попытки

**Основание:** [R54](../../0-vibes/prd/PRD.md#r54), [BT-22](../../1-business-tasks/planning/BT-22-PLANNING-PROFILE-PROGRESS.md), [MOD-10](../modules/MOD-10-PROGRESS.md).

**Актор, событие, сущность:** [ACTOR-2](../actors/ACTOR-2-USER-IN-AUTH.md), [EVT-26](../events/EVT-26-RECENT-ATTEMPT-SELECTED-IN-PROGRESS.md), [ENT-18](../entities/ENT-18-PROGRESS-SUMMARY-IN-PROGRESS.md).

## Триггер

Пользователь выбирает строку последней попытки.

## Предусловия

Пользователь вошёл, список попыток загружен в профиле.

## Пути

### <a id="uc-42-p-01"></a>UC-42-P-01 — переход к задаче

Приложение открывает штатный маршрут задачи `/task/{task_slug}` из выбранной
строки. Обрабатывается именно slug этой попытки, даже если ветка каталога
сохраняла другую задачу. Дальнейшая загрузка, отсутствие задачи и ошибка
сервера обрабатываются существующим
[UC-15](UC-15-ACTOR-4-EVT-12-ENT-6-PROBLEM-SHOWN-IN-CATALOG.md).
При возврате пунктом «Профиль» его данные запрашиваются заново.

**Исход:** UC-42-O-01 — открыт маршрут выбранной задачи

## Постусловия

Записи попыток сохранены. Состояние самой задачи определяется её актуальной
доступностью.
