# UC-12: Запуск приложения

**Основание:** [R15](../../0-vibes/prd/PRD.md#r15), [R16](../../0-vibes/prd/PRD.md#r16), [BT-6](../../1-business-tasks/planning/BT-6-PLANNING-BUILD-CONFIG.md), [MOD-3](../modules/MOD-3-CONFIG.md).

**Актор, событие, сущность:** [ACTOR-1](../actors/ACTOR-1-VISITOR-IN-AUTH.md), [EVT-10](../events/EVT-10-APP-STARTED-IN-CONFIG.md), [ENT-5](../entities/ENT-5-BUILD-CONFIG-IN-CONFIG.md).

## Триггер

Посетитель открывает приложение в браузере.

## Предусловия

Приложение собрано с параметрами `--dart-define` или без них.

## Пути

### <a id="uc-12-p-01"></a>UC-12-P-01 — параметры заданы, подключение удалось

Приложение запускается и дальше ведёт себя по состоянию входа.

**Исход:** UC-12-O-01 — приложение запущено

### <a id="uc-12-p-02"></a>UC-12-P-02 — адреса или ключа нет

Экран «Приложение не сконфигурировано» с причиной: «Не заданы SUPABASE_URL и SUPABASE_ANON_KEY. Соберите приложение с параметрами --dart-define.».

**Исход:** UC-12-O-02 — показан экран «не сконфигурировано»: нет параметров

### <a id="uc-12-p-03"></a>UC-12-P-03 — подключиться к Supabase не удалось

Тот же экран с причиной: «Не удалось подключиться к Supabase. Проверьте SUPABASE_URL и SUPABASE_ANON_KEY.».

**Исход:** UC-12-O-03 — показан экран «не сконфигурировано»: нет подключения

## Постусловия

Без параметров и без подключения приложение дальше экрана «не сконфигурировано» не идёт.
