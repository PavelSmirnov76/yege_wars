# UC-10: Вход

supersedes: [UC-2](obsolete/UC-2-ACTOR-1-EVT-2-ENT-3-SESSION-STARTED-IN-AUTH.md)

**Основание:** [R7](../../0-vibes/prd/PRD.md#r7), [R9](../../0-vibes/prd/PRD.md#r9), [BT-2](../../1-business-tasks/planning/BT-2-PLANNING-SIGN-IN.md), [MOD-1](../modules/MOD-1-AUTH.md).

**Актор, событие, сущность:** [ACTOR-1](../actors/ACTOR-1-VISITOR-IN-AUTH.md), [EVT-2](../events/EVT-2-SIGNED-IN-IN-AUTH.md), [ENT-3](../entities/ENT-3-SESSION-IN-AUTH.md).

## Триггер

Посетитель открывает любой адрес приложения.

## Предусловия

Нет.

## Пути

### <a id="uc-10-p-01"></a>UC-10-P-01 — без входа, верные логин и пароль

Пока состояние входа неизвестно, видна заставка. Без входа приложение показывает экран входа и запоминает адрес. После верных логина и пароля открывается запомненный адрес или главная.

**Исход:** UC-10-O-01 — сессия начата, открыт нужный адрес

### <a id="uc-10-p-02"></a>UC-10-P-02 — неверные логин или пароль

Экран входа показывает сообщение над формой; посетитель остаётся на экране входа.

**Исход:** UC-10-O-02 — вход отклонён

### <a id="uc-10-p-03"></a>UC-10-P-03 — логин или пароль не по правилам

Ошибки показываются у полей, запрос не уходит.

**Исход:** UC-10-O-03 — данные отклонены

### <a id="uc-10-p-04"></a>UC-10-P-04 — сбой связи или сервера

Экран входа показывает сообщение об ошибке.

**Исход:** UC-10-O-04 — вход не выполнен: сбой

### <a id="uc-10-p-05"></a>UC-10-P-05 — сессия уже есть

После перезагрузки страницы сессия восстанавливается, и адрес открывается без экрана входа. Вошедшего с `/login` и `/register` приложение уводит на главную.

**Исход:** UC-10-O-05 — адрес открыт без входа заново

### <a id="uc-10-p-06"></a>UC-10-P-06 — сессия есть, но профиль не прочитан

Пользователь остаётся снаружи: приложение показывает экран входа, над полями — сообщение-ошибка с причиной, например «Профиль пользователя не найден. Обратитесь к преподавателю.».

**Исход:** UC-10-O-06 — вход не выполнен: профиль не прочитан

## Постусловия

Сессия сохраняется до выхода, в том числе при перезагрузке страницы.
