# UC-29: Выкладка сайта

**Основание:** [R42](../../0-vibes/prd/PRD.md#r42), [BT-16](../../1-business-tasks/planning/BT-16-PLANNING-SITE.md), [MOD-9](../modules/MOD-9-SITE.md).

**Актор, событие, сущность:** [ACTOR-5](../actors/ACTOR-5-OWNER-IN-SITE.md), [EVT-24](../events/EVT-24-SITE-DEPLOYED-IN-SITE.md), [ENT-16](../entities/ENT-16-SITE-IN-SITE.md).

## Триггер

Владелец запускает выкладку в GitHub Actions.

## Предусловия

Pages включён с источником «GitHub Actions»; в секретах GitHub заданы
`SUPABASE_URL` и `SUPABASE_ANON_KEY`.

## Пути

### <a id="uc-29-p-01"></a>UC-29-P-01 — сайт выложен

Текущий `main` собран с конфигурацией сборки и опубликован: по адресу сайта
открывается новая версия.

**Исход:** UC-29-O-01 — сайт обновлён

### <a id="uc-29-p-02"></a>UC-29-P-02 — сборка не прошла

Сборка упала — в том числе потому, что не задан `SUPABASE_URL` или
`SUPABASE_ANON_KEY`. Выкладка останавливается, причина — в логе прогона в
Actions; по адресу сайта — прежняя версия.

**Исход:** UC-29-O-02 — сайт прежний

## Постусловия

База не меняется. Без запуска владельцем сайт не обновляется.
