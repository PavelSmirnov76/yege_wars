# ENT-12: Статья

**Модуль:** [MOD-7](../modules/MOD-7-REFERENCE.md).

Таблица `reference_articles`.

| Поле | Тип | Правило |
|---|---|---|
| `slug` | text | `^[a-z0-9-]{3,64}$`, уникален; адрес статьи и ссылки на неё |
| `title` | text | название |
| `summary` | text | описание |
| `content_md` | text | текст в разметке Markdown |
| `ege_numbers` | smallint[] | номера КЕГЭ; бывает пустым |
| `tags` | text[] | теги; бывает пустым |
| `level` | smallint | 1 — базовый, 2 — средний, 3 — продвинутый |
| `reading_minutes` | smallint | время чтения в минутах, больше 0 |
| `is_published` | boolean | опубликована |
| `theme_code` | text | тема, которую объясняет статья; у темы не больше одной статьи |

- Читают вошедшие: опубликованные — все, неопубликованные — только
  администратор (политика `reference_articles_select`); пишет только Content
  API.
- Клиент читает карточку статьи без текста — для списка и справки, статью
  целиком по `slug` и словарь «`slug` — название» — для ссылок.
