# ENT-9: Запуск

**Модуль:** [MOD-5](../modules/obsolete/MOD-5-EDITOR.md). **Код:** [ENT-8](obsolete/ENT-8-CODE-IN-EDITOR.md). **Файлы:** [ENT-7](ENT-7-FILE-IN-CATALOG.md).

Выполнение кода в браузере. Живёт в памяти вкладки до следующего запуска; в
базу не попадает.

| Поле | Что это |
|---|---|
| исход | `finished` — завершилась сама, `failed` — ошибка, `stopped` — «Стоп», `timedOut` — дольше таймаута |
| вывод | что программа напечатала (`stdout`) |
| ошибки | `stderr`: трассировка ошибки или причина, по которой среда не запустилась |
| длительность | время от нажатия «Запустить» до итога |

- Среда — Pyodide 314.0.7 (Python 3.14) в модульном Web Worker, одна на
  вкладку. Загружается при первом запуске с jsDelivr, при неудаче — с unpkg.
- Перед запуском файлы задачи записываются в виртуальную файловую систему под
  своими именами, файлы прошлого запуска удаляются. Ввод — строки поля «Ввод
  (stdin)»; когда они кончились, `input()` получает `EOFError`.
- Вывод и ошибки обрезаются до 20 000 символов с припиской, сколько скрыто.
- Таймаут — 60 с с нажатия «Запустить», вместе с загрузкой среды. «Стоп» и
  таймаут убивают воркер; следующий запуск создаёт новый.
- Пространство имён Python общее для запусков, пока воркер жив.
- Одновременно идёт только один запуск.
