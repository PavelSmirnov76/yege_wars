# ENT-1: Учётная запись

**Модуль:** [MOD-1](../modules/MOD-1-AUTH.md).

Запись Supabase Auth, таблица `auth.users`.

| Поле | Что это |
|---|---|
| `id` | uuid пользователя |
| `email` | техническая почта `<логин в нижнем регистре>@ege.local`; писем не шлём |
| пароль | хранит Supabase Auth, в открытом виде нигде не лежит |
| `raw_user_meta_data.username` | логин, как его ввёл посетитель, — для триггера регистрации |

- Создаётся регистрацией. Перед вставкой триггер `check_registration_open`
  отказывает `[registration_closed]`, если регистрация закрыта; после вставки
  триггер `handle_new_user` создаёт профиль.
- Пароль меняет только `admin_reset_password`.
- Связь: профиль — один к одному, `profiles.id = auth.users.id`, удаляется
  вместе с учётной записью.
