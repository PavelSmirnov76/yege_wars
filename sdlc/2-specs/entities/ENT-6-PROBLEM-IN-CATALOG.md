# ENT-6: Задача

**Модуль:** [MOD-4](../modules/MOD-4-CATALOG.md).

Таблица `tasks`. Клиент читает представление `tasks_public` — только задачи со
статусом `published`.

| Поле | Тип | Правило |
|---|---|---|
| `id` | uuid | ключ |
| `slug` | text | уникален; адрес страницы — `/task/<slug>` |
| `ege_number` | smallint | номер КЕГЭ 1–27; `null` — задача банка без номера |
| `title` | text | название |
| `statement_md` | text | условие в Markdown |
| `difficulty` | smallint | 1 — простая, 2 — средняя, 3 — сложная |
| `answer_format` | text | `single` — одно число, `pair` — два числа, `multi` — несколько чисел, `string` — строка |
| `tags` | text[] | теги |
| `source` | text | источник; может быть пустым |
| `origin` | text | `human`, `ai` или `fipi` |
| `status` | text | `draft`, `review`, `published`; в `tasks_public` не входит |

- Эталонное решение (`reference_solution`) и разбор (`answer_explanation`)
  лежат в `tasks`, но не выданы ни одной роли клиента и в `tasks_public` не
  входят.
- Читает любой вошедший: опубликованные задачи (политика `tasks_select`;
  администратору — все). Вставки, изменения и удаления через API нет — задачи
  пишет Content API.
- Неизвестный формат ответа клиент читает как `string`, неизвестную сложность —
  как среднюю.
- Доля решивших — `get_task_stats()`: по каждой опубликованной задаче сколько
  учеников её пробовали, сколько решили верно и процент решивших с точностью до
  0,1. Попытки администраторов не считаются.
