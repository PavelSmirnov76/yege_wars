# ENT-5: Конфигурация сборки

**Модуль:** [MOD-3](../modules/MOD-3-CONFIG.md).

| Параметр | Что это |
|---|---|
| `SUPABASE_URL` | адрес проекта Supabase |
| `SUPABASE_ANON_KEY` | публичный ключ проекта (`sb_publishable_…`) |

- Передаются при сборке и запуске параметрами `--dart-define`; значений по
  умолчанию в коде нет.
- Локальные значения лежат в незаливаемом `supabase/.env.local`; в репозитории
  их нет.
- Приложение сконфигурировано, когда заданы оба параметра.
