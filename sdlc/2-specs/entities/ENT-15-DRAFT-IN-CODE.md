# ENT-15: Черновик

supersedes: [ENT-8](obsolete/ENT-8-CODE-IN-EDITOR.md)

**Модуль:** [MOD-8](../modules/MOD-8-CODE.md). **Пользователь:** [ENT-2](ENT-2-PROFILE-IN-AUTH.md). **Задача:** [ENT-6](ENT-6-PROBLEM-IN-CATALOG.md).

Код задачи пользователя, сохранённый в базе: таблица `public.drafts`, одна
строка на пользователя и задачу.

| Поле | Тип | Что это |
|---|---|---|
| `user_id` | `uuid` → `profiles.id` | автор |
| `task_id` | `uuid` → `tasks.id` | задача |
| `code` | `text` | код из поля кода |
| `updated_at` | `timestamptz` | время последней записи |

- Первичный ключ — (`user_id`, `task_id`): у пользователя по задаче один
  черновик. С пользователем или задачей удаляется и черновик.
- Строку читает, записывает и удаляет только её автор (`user_id =
  auth.uid()`); записывать можно только по задаче, которую он видит
  (`is_task_visible`). Чужие черновики не видны никому, в том числе
  администратору.
- Клиент пишет строку upsert по ключу и удаляет её напрямую; RPC нет.
- Код из одних пробельных символов не хранится: строку удаляют.
- В браузере черновик не хранится.
- Отправленный ответ, как и раньше, уносит копию кода в попытку.
