# ENT-17: Тестовая учётная запись

**Модуль:** [MOD-1](../modules/MOD-1-AUTH.md). **Учётная запись:** [ENT-1](ENT-1-ACCOUNT-IN-AUTH.md).

Обычная учётная запись ученика — роль `student`, — в которую входит кнопка
«Тестовый вход». Её логин и пароль приложение получает при сборке.

| Параметр | Что это |
|---|---|
| `TEST_LOGIN_USERNAME` | логин тестовой учётной записи |
| `TEST_LOGIN_PASSWORD` | её пароль |

- Передаются при сборке и запуске параметрами `--dart-define`; значений по
  умолчанию в коде нет.
- Локальные значения лежат в незаливаемом `supabase/.env.local`, на сайте —
  в секретах GitHub с теми же именами; в репозитории их нет.
- Тестовый вход есть, когда заданы оба параметра. Без них сайт выкладывается
  и приложение запускается как обычно — без кнопки.
- Значения попадают в код сборки: на сайте их может прочитать любой. Так и
  задумано — учётной записью может воспользоваться любой посетитель.
- В базе это обычная учётная запись и профиль ученика: черновики, попытки и
  публикации у неё одни на всех, кто вошёл.
- Учётную запись заводит владелец, пока регистрация открыта.
