# ENT-4: Настройки

**Модуль:** [MOD-2](../modules/MOD-2-MANAGEMENT.md).

Таблица `app_settings`: `key` — имя настройки, `value` — jsonb.

| Ключ | Значение |
|---|---|
| `registration_open` | `true` — регистрация открыта, `false` — закрыта |

- Набор ключей задают миграции: вставка и удаление через API закрыты. Другие
  ключи таблицы — вне этого среза.
- Читает любой вошедший; посетителю флаг регистрации отдаёт
  `is_registration_open()`.
- Меняет только администратор (политика `app_settings_admin_update`). Попытка
  остальных не падает, а меняет 0 строк.
