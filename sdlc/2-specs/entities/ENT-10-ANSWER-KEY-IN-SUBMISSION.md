# ENT-10: Эталонный ответ

**Модуль:** [MOD-6](../modules/MOD-6-SUBMISSION.md). **Задача:** [ENT-6](ENT-6-PROBLEM-IN-CATALOG.md).

Таблица `task_answers`.

| Поле | Тип | Правило |
|---|---|---|
| `task_id` | uuid | ключ, ссылка на задачу; удаляется вместе с ней |
| `answer` | text | эталонный ответ в исходном виде |

- Клиентам недоступна: политик нет, привилегии у `anon` и `authenticated`
  отозваны — прямое чтение отвечает `permission denied` и ученику, и
  администратору.
- С ответом пользователя эталон сравнивает только `submit_solution`. Пишет
  эталон Content API.
- Задача без эталонного ответа считает неверным любой ответ.
