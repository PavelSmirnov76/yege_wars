# Модули

Функциональные части продукта — **как всё складывается**.

Модуль — единица, на которую ложится бизнес-задача планирования. Его имя —
ключ, вокруг которого строится `2-specs/`: оно становится суффиксом
`-IN-{MODULE}` в имени каждой сущности, события, актора и UC. Ученик в модуле
авторизации — `ACTOR-1-STUDENT-IN-AUTH`.

Модуль покидает папку, когда из него выведены спеки. Что в модуле лежит, видно
по суффиксу и по `INDEX.md`: сам модуль этого не перечисляет.

## Почему имя так важно

Имя копируется в каждое имя спеки, поэтому разнобой в нём молча раздваивает
весь граф. Модули определяют первыми, называют словами PRD и замораживают;
дисциплина имени — в [AGENTS.md](AGENTS.md).
