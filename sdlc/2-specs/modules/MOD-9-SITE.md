# MOD-9: Сайт

**Основание:** [BT-16](../../1-business-tasks/planning/BT-16-PLANNING-SITE.md).

## Область

Сайт на GitHub Pages: сборка приложения из текущего `main` с конфигурацией
сборки и выкладка этой сборки по запуску владельца.

## Граница

Не владеет ни содержимым приложения, ни базой: что показывает сайт, решают
остальные модули. Значений конфигурации сборки не хранит — они в секретах
GitHub.
