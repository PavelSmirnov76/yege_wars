# 7 — Безопасность

Проверка безопасности перед тем, как что-то покинет машину разработчика. Это
**контроль безопасности**: утечки, доступы и уязвимости ловят здесь, а не на
боевой.

Проверка пройдена, когда в ней нет открытых находок; дальше — `8-deploy/`.

## Что здесь

- проверки `SEC-{n}`: что проверено, находки, их серьёзность и как закрыты.
