# 9 — Наблюдение

Наблюдение за выпущенной системой (`8-deploy/`). Это **замыкает петлю**:
сигналы отсюда возвращаются в `1-business-tasks/observation/` и становятся
следующим кругом планирования и работы.

Как и наблюдение стадии 1, сигналы разобраны по серьёзности.

## Состав

- `errors/` — сбои и инциденты на боевой, которые требуют действий.
- `warnings/` — риски и ухудшения, пока они не стали ошибками.
- `infos/` — нейтральные сигналы, числа, заметки об использовании.

```
8-deploy/ → 9-observation/ → 1-business-tasks/observation/ → …
                             (обратно в планирование)
```
