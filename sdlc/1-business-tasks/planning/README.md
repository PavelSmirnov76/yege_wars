# Планирование

Половина стадии 1, где из сигналов `observation/` и целей продукта складывают
планы и приоритеты.

Бизнес-задачи планирования (`BT-{n}-PLANNING-…`) — прямой источник спек в
`2-specs/`: каждая спека ссылается на бизнес-задачу, которая её вызвала.

Это очередь работы: следующее задание постановщик предлагает из открытых
бизнес-задач планирования, а выбирает владелец. Какие закрыты, показывает
`INDEX.md`.

Правила — в [AGENTS.md](AGENTS.md).
