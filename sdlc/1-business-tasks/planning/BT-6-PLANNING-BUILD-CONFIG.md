# BT-6: Конфигурация сборки вне репозитория

**Доказательство:** [0-vibes/raw/2026-10-08/keys-in-repository.md](../../0-vibes/raw/2026-10-08/keys-in-repository.md). **Наблюдение:** [BT-5](../observation/warnings/BT-5-WARNING-KEYS-IN-REPOSITORY.md).

**Служит:** [R15](../../0-vibes/prd/PRD.md#r15), [R16](../../0-vibes/prd/PRD.md#r16).

Адрес проекта и публичный ключ приложение получает при сборке, а не из кода.
Без них — понятный экран «Приложение не сконфигурировано». После этого старый
публичный ключ перевыпускается: в истории git он останется мёртвым.
