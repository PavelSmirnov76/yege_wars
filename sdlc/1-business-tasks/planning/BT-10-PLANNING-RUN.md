# BT-10: Запуск программы в браузере

**Доказательство:** [0-vibes/raw/2026-10-08/as-built-problems.md](../../0-vibes/raw/2026-10-08/as-built-problems.md) — проход «как построено».

**Служит:** [R24](../../0-vibes/prd/PRD.md#r24), [R25](../../0-vibes/prd/PRD.md#r25), [R26](../../0-vibes/prd/PRD.md#r26).

Ученик пишет и запускает программу на Python прямо на странице задачи, без
установки Python: программа открывает файлы задачи по именам, как на экзамене,
читает ввод и печатает в консоль. Зациклившуюся программу можно остановить, а
интерфейс при этом не зависает. Код не теряется между заходами на задачу.
