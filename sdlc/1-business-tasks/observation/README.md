# Наблюдение

Половина стадии 1, куда собирают сигналы от работающей системы, людей и
эксплуатации. Из них потом складывают планы. Сигналы разбирают по серьёзности.

## Состав

- `errors/` — сломано и требует действий.
- `warnings/` — риски и ухудшения, на которые стоит смотреть, пока они не стали
  ошибками.
- `infos/` — нейтральные сигналы, числа, заметки для контекста.

Наблюдения питают `1-business-tasks/planning/`.

Правила — в [AGENTS.md](AGENTS.md).
