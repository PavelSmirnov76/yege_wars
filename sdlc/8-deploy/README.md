# 8 — Выпуск

Выкладка клиента, прошедшего проверку безопасности, на GitHub Pages. Базу
меняют задания — миграциями; выпуск записывает, какие миграции стоят на боевой
базе. Так собранное, проверенное и одобренное доходит до учеников.

Выпуск покидает стадию, когда работает и за ним следит `9-observation/`.

## Что здесь

- выпуски `REL-{n}`: что выпущено, куда, какие миграции стоят на боевой базе,
  как выкатывали и как откатить.
