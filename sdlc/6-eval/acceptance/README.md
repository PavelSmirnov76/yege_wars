# Приёмки

Вердикт по каждой сдаче: «принято» или «возврат» — и таблица проверок, которые
постановщик сделал сам. Итог одобряет владелец.

Задание закрыто, когда его последняя приёмка — «принято». После возврата
исполнитель делает следующую сдачу, и её принимают заново.

Правила — в [AGENTS.md](AGENTS.md).
