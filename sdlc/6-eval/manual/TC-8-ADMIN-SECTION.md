# TC-8: Раздел «Админка» — у администратора есть, у ученика нет

**Цель:** установить, что пункт и экран «Админка» есть только у
администратора, адрес `/admin` уводит ученика на главную, а вызов `admin_*`
от ученика отклоняет база.

**Пути UC:** [UC-5-P-01](../../2-specs/use-cases/UC-5-ACTOR-2-EVT-5-ENT-2-SECTION-SHOWN-IN-AUTH.md#uc-5-p-01), [UC-5-P-02](../../2-specs/use-cases/UC-5-ACTOR-2-EVT-5-ENT-2-SECTION-SHOWN-IN-AUTH.md#uc-5-p-02), [UC-6-P-01](../../2-specs/use-cases/UC-6-ACTOR-2-EVT-6-ENT-2-ACTION-DENIED-IN-AUTH.md#uc-6-p-01).

**Приоритет:** высокий — защита данных учеников.

## Предусловия

- Сборка `main` по `README.md`, раздел «Локальная сборка с тестовым
  проектом», на `http://localhost:8080/`.
- Учётные записи из `supabase/.env.dev.local`: ученик `TEST_LOGIN_USERNAME` /
  `TEST_LOGIN_PASSWORD`, администратор `CONTENT_API_LOGIN` /
  `CONTENT_API_PASSWORD`. API — `SUPABASE_URL` и `SUPABASE_ANON_KEY` оттуда
  же; вход в API — `POST /auth/v1/token?grant_type=password` с почтой
  `<логин>@ege.local`.
- Браузер без сохранённой сессии сайта.
- Каждый экран — на 360 и 1440 px (`6-eval/manual/AGENTS.md`, «Вид экрана»).

## Шаги

| № | Шаг и входные данные | Ожидаемый результат | Путь |
|---|---|---|---|
| 1 | Войти учеником | В навигации — «Каталог», «Справочник», «Профиль»; пункта «Админка» нет | UC-5-P-02 |
| 2 | Открыть `http://localhost:8080/#/admin` | Открывается главная — «Каталог» | UC-5-P-02 |
| 3 | API от ученика: `POST /rest/v1/rpc/admin_set_role`, тело `{"p_user_id": "<id ученика>", "p_role": "admin"}` | Ошибка с сообщением «[forbidden] Доступно только администратору.»; в «Профиле» ученика после перезагрузки — «Роль: Ученик» | UC-6-P-01 |
| 4 | Выйти; войти администратором | В навигации есть «Админка» | UC-5-P-01 |
| 5 | Нажать «Админка» | Заголовок «Админка» и «Раздел в разработке» | UC-5-P-01 |
| 6 | Открыть `http://localhost:8080/#/admin` адресом | Тот же экран «Админка» | UC-5-P-01 |
