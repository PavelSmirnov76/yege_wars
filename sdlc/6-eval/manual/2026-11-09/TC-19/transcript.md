### Ограничения драйвера и обходы

Исходный драйвер сохранялся без изменений. Для mobile отказались от внешнего CDP attach: тот вариант менял эффективный DPR/viewport. Mobile UI ввод выполнялся через настоящий `page.touchscreen.tap` на context с `hasTouch=true`, DPR 1, Pixel 5 UA. Для Flutter placeholder размером 1×1 за viewport tap в его центр не включал semantics; использовались focus placeholder + Enter. При переключении аккаунтов логин вводился физическими taps по форме, так как locator по placeholder ждал выключенную semantics. Один прерванный locator завершил Chromium; новый headless запуск показал пустой Flutter canvas и завершился ошибкой Chromium permissions. Повторный headful запуск с разрешённым запуском браузера прошёл, без пересборки. Продукт и замороженный кейс не менялись.
